How to Use Custom Images

Want to replace default placeholders with your actual photos (e.g., logo.png or affogato photos)? Here are two simple, reliable ways:

1 Local Repo / Folder

Save your image files (e.g. logo.png, hero.jpg) in the exact same folder as this index.html file.

2 Free Image Hosting (Imgur / Cloudinary)

  1. Upload your photo to Imgur.com or Postimages.org.
  2. Copy the Direct Image Link ending in .jpg or .png.
  3. Replace the src="..." attribute in this code with your link!

Automatic Fallback Active

This app uses onerror="handleImageError(this)" on every image. If an image link fails or is missing, a beautiful SVG vector fallback is shown immediately—so your app will never crash or display broken images!
